<objective>
Fix Salesforce Tooling API error when creating TraceFlag records.

**Issue:** When calling `connection.tooling.create('TraceFlag', {...})` without the `LogType` field, Salesforce API returns "LogType is required" error even though the field is documented as optional with a default value.

**Solution:** Add `LogType: 'DEVELOPER_LOG'` (the default type) to the TraceFlag creation payload in `createTraceFlag()` function.

**Impact:** Resolves 450+ traces failing to create, enabling the trace command to work end-to-end.
</objective>
