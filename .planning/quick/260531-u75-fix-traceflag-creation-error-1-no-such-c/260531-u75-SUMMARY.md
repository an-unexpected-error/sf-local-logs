## What Was Done

### Task 1: Remove StartTime from TraceFlag creation payload

**File modified:** `src/utils/trace-helper.ts`

**Change:** 
- Removed `StartTime: startTime.toISOString()` from the `connection.tooling.create('TraceFlag', {...})` payload (line 99)
- Added explanatory comment: `// StartTime is read-only on TraceFlag; Salesforce sets it automatically`
- Kept `startTime` variable in use for `expirationDate` calculation (unchanged logic)
- Final payload now contains only three fields: `TracedEntityId`, `DebugLevelId`, `ExpirationDate` (all writable, required)

**Why:** The Salesforce Tooling API TraceFlag object has `StartTime` as a read-only field (set automatically by Salesforce upon record creation). Passing it in the create payload caused: "Error (1): Failed to create trace flag. TraceFlag creation failed: No such column 'StartTime' on sobject of type TraceFlag. Verify you have TraceFlag creation permission."
