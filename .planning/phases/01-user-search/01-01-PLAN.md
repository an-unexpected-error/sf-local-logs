<threat_model>
## Trust Boundaries

| Boundary | Description | Data Flow |
|----------|-------------|-----------|
| User Input → SOQL Query | Untrusted user search term crosses into Salesforce API query | buildSearchQuery() escapes single quotes to prevent injection |
| Org Connection → Plugin | Trusted Salesforce org returns authenticated connection | @salesforce/core handles OAuth; plugin receives authenticated connection |
| Search Results → Terminal Output | Trusted Salesforce data displayed to user | No sensitive fields exposed; user data filtered at query time (LIMIT, WHERE) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
