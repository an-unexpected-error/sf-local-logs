<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user CLI → keyword string | --keyword value is user-supplied; used in includes() check only |
| filter-helper → filesystem | reads/renames files within sessionDir only; sessionDir is internally constructed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Tampering | scanFirstNLines — keyword in string match | accept | keyword used only in String.prototype.includes(); no regex injection risk; D-04 explicitly bans regex |
| T-04-02-02 | Tampering | filterDownloadedLogs — sessionDir path | accept | sessionDir derived from createSessionDirectory() which applies sanitizePathComponent(); user cannot inject custom path in v1 |
| T-04-02-03 | DoS | scanFirstNLines — large log files | mitigate | readline.createInterface streams line-by-line; maxLines=100 caps scan at 100 lines regardless of file size; never buffers whole file |
| T-04-02-04 | Tampering | readdir entries — EISDIR from rejected/ dir | mitigate | filter entries with f.endsWith('.json') excludes 'rejected' directory entry naturally (Pitfall 2 mitigation) |
| T-04-02-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages; all imports are Node.js built-ins (node:readline, node:fs/promises, node:path) |
</threat_model>
